
\# FitFlow Redesign



FitFlow mobile app redesign — HCI coursework (IT3060). Research, design, usability testing and technology architecture.



\## Recommended Technology Stack



\- \*\*Frontend\*\*: React Native + React Native Web

\- \*\*Backend API\*\*: NestJS (Node.js / TypeScript)

\- \*\*AI Service\*\*: Python / FastAPI

\- \*\*Primary Database\*\*: PostgreSQL

\- \*\*Cache / Real-time\*\*: Redis

\- \*\*Object Storage\*\*: S3 (or equivalent)

\- \*\*Authentication\*\*: Auth0



\## Documentation



\- Lab 05 — Technology comparison and architecture



\## Getting started



```bash

\# Frontend

cd frontend \&\& npm install \&\& npm start



\# Backend

cd backend \&\& npm install \&\& npm run start:dev



\# AI service

cd ai-service \&\& pip install -r requirements.txt \&\& uvicorn app.main:app --reload

```
